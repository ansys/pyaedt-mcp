





:class:`WindowResult`
=====================


.. py:class:: ansys.aedt.mcp.html_window.WindowResult

   
   Outcome of an attempt to open a detached HTML window.



   :Attributes:

       **opened** : :ref:`bool <python:bltin-boolean-values>`
           Whether a window or browser was launched.

       **method** : :class:`python:str`
           ``"app_window"``, ``"default_browser"``, or ``"none"``.

       **path** : :class:`python:str` | :data:`python:None`
           Wrapper file that was opened, if one was written.

       **browser** : :class:`python:str` | :data:`python:None`
           Browser executable used for ``"app_window"``.

       **error** : :class:`python:str` | :data:`python:None`
           Reason the window could not be opened.

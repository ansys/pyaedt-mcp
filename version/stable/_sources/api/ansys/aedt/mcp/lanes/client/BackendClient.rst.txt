





:class:`BackendClient`
======================


.. py:class:: ansys.aedt.mcp.lanes.client.BackendClient(port: int, host: str = '127.0.0.1', path: str = DEFAULT_PATH, auth_token: str | None = None)

   
   MCP client bound to one lane backend.

   Use it as an async context manager:

   >>> async with BackendClient(port=8090, auth_token=token) as backend:  # doctest: +SKIP
   ...     port = await backend.discover_aedt_port()

   :Parameters:

       **port** : :class:`python:int`
           HTTP port of the lane.

       **host** : :class:`python:str`, default: "127.0.0.1"
           Host of the lane.

       **path** : :class:`python:str`, default: "/mcp/"
           MCP endpoint path.

       **auth_token** : :class:`python:str`, :obj:`optional`
           Bearer token of the lane.

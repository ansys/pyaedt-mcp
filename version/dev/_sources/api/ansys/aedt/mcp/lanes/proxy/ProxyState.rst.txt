





:class:`ProxyState`
===================


.. py:class:: ansys.aedt.mcp.lanes.proxy.ProxyState

   
   Routing state of one proxy process.


   :Parameters:

       **host** : :class:`python:str`
           Host every lane listens on.

       **current_lane** : :class:`python:str`, :obj:`optional`
           Selected lane, ``None`` until ``spawn_lane`` or ``switch_lane``.

       **startup_timeout** : :class:`python:float`
           Seconds a new lane gets to bind its port.

       **probe_timeout** : :class:`python:float`, :obj:`optional`
           Seconds a lane gets to answer a status probe. ``None`` waits forever.

       **handshake_timeout** : :class:`python:float`
           Seconds a lane gets to answer the MCP handshake of a routed call.

       **backend_args** : :class:`python:list`\[:class:`python:str`]
           Additional ``ansys-aedt-mcp`` arguments for spawned lanes.

       **in_flight** : :class:`python:dict`\[:class:`python:int`, :class:`python:tuple`\[:class:`python:str`, :class:`python:str`, :class:`python:float`]]
           Pending routed calls mapped to their lane, tool, and start time.
